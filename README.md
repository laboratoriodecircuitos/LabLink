# LabLink

Aplicativo Android nativo em Kotlin para controlar projetos Arduino via Bluetooth Classic usando módulos HC-05 ou HC-06.

## Objetivo

O LabLink será uma ferramenta didática do Laboratório de Circuitos para permitir que alunos controlem projetos eletrônicos pelo celular.

## Escopo inicial

- App Android nativo em Kotlin.
- Comunicação Bluetooth Classic / SPP.
- Arduino Uno/Nano com HC-05 ou HC-06.
- Controle de LED.
- Controle PWM.
- Controle de servo.
- Controle de motores.
- Terminal serial simples.
- Firmware Arduino de exemplo.
- Kit de integração para projetos Arduino existentes.

## Compatibilidade

- Android: escopo inicial.
- iOS: fora do escopo inicial.
- Futuramente poderá existir uma linha BLE com ESP32.

## Diretriz de desenvolvimento

A fundação local do projeto será criada manualmente via PowerShell. O Codex será usado depois como auxiliar de implementação.

## Laboratório de Circuitos

Projeto conduzido dentro do ecossistema do Laboratório de Circuitos, com foco em ensino cuidadoso, eletrônica prática, responsabilidade técnica e postura anti-gambiarra.
