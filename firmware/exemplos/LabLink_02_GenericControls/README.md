# LabLink_02_GenericControls

Firmware didatico para testar o protocolo generico do LabLink com Arduino Uno/Nano e HC-05/HC-06.

## Comandos compativeis

- PING
- LED:ON
- LED:OFF

## Comandos genericos

- DIGITAL:D2:ON
- DIGITAL:D2:OFF
- PWM:D3:128
- PULSE:D4:500
- READ:A0

## Observacao

Este firmware e para fins didaticos e prototipagem. Nao usar em aplicacoes criticas, medicas, industriais, rede eletrica ou seguranca sem validacao adequada.
